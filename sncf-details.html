An end-to-end railway business intelligence architecture that transforms raw transactional data into a reliable Data Warehouse, multidimensional analysis environment, and interactive KPI reporting system.

Project Overview & Goal

This project designs an end-to-end decision-making architecture for the railway sector. Raw transactional data is transformed into a structured Data Warehouse to address data quality issues, isolated source systems, and analytical performance constraints while giving decision-makers a consistent view of business activity.

Operational Architecture & ETL (Talend & MySQL)

The Operational Database Architecture (DBO) receives source file injections into MySQL. Talend Open Studio orchestrates the ETL flow, applies strict normalization rules, cleans the source data, and prepares reliable fact-table records for analytical modeling.

Multidimensional Modeling (Data Warehouse)

The Data Warehouse is structured as a Star Schema centered on the sales fact table and connected to dedicated dimension tables. This model keeps joins simple, makes business measures consistent, and improves query performance for recurring analytical workloads.

OLAP Analysis & Microsoft Ecosystem

The analytical environment is migrated into the Microsoft ecosystem with SQL Server as the relational platform. An SSAS cube pre-aggregates business calculations, while MDX queries handle complex temporal and geographical dimensions for flexible drill-down and comparison.

Reporting & Data Visualization (Power BI)

The decision-making restitution environment turns validated metrics into visual, interactive Key Performance Indicators. Power BI dashboards support precise activity tracking and help stakeholders explore the performance of the railway business from multiple perspectives.
