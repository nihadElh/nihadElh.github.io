RealTime-Aero-Maintenance

A hybrid Remaining Useful Life prediction system that combines real-time streaming, distributed storage, and adaptive machine learning for the NASA CMAPSS dataset.

GitHub repository ↗ Open dashboard demo ↓ Read project README ↗

Project Overview & Goal

This project implements an end-to-end hybrid RUL (Remaining Useful Life) prediction system for aircraft engine fleets. Using the NASA CMAPSS dataset, it combines sensor data streaming, Big Data infrastructure, and machine learning to estimate how many operating cycles remain before maintenance is required.

Architecture & Data Flow

  1. 1. Ingestion: a simulated fleet publishes temperature, pressure, and vibration sensor events through Apache Kafka.
  2. 2. Speed Layer: a Python consumer applies temporal windowing and produces real-time RUL predictions.
  3. 3. Cold Storage: raw events and predictions are archived in Hadoop HDFS for auditability and future retraining.
  4. 4. Serving Layer: the latest results are persisted in MySQL for fast application queries.
  5. 5. Dashboard: PHP and Chart.js provide interactive fleet monitoring and maintenance alerts.

Hybrid Machine Learning Strategy

  • Cold Start mode: for engines with fewer than 30 cycles, Support Vector Regression (SVR) predicts RUL point by point with limited history.
  • Cruise mode: after 30 cycles, CatBoost Regressor uses sliding windows to model temporal dependencies and changing wear patterns.
  • RUL Clipping: predictions are capped at 130 cycles to reduce early-life noise and improve model convergence.
