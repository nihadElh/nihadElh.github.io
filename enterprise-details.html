Enterprise Knowledge Brain

An intelligent AI assistant for querying personal and enterprise documents across PDFs, images, and scans, powered by multi-source OCR, semantic retrieval, and Llama-3.

GitHub repository ↗ Open demo resources ↓ Read project README ↗

Project Overview & Goal

Enterprise Knowledge Brain is an intelligent AI assistant that answers complex questions over personal and enterprise documents. It combines Retrieval-Augmented Generation (RAG) with multi-source OCR for PDFs, images, and scans, using Llama-3 to return contextual answers with reliable document references.

Architecture & Data Flow

  1. 1. File ingestion and chunking: LangChain loads and cleans incoming files, then splits their content with a recursive character text splitter.
  2. 2. Embedding transformation: each text segment is converted into a semantic vector with sentence-transformers.
  3. 3. Vector storage: embeddings and metadata are indexed and persisted in ChromaDB for fast similarity retrieval.
  4. 4. Semantic intent routing: the LLM classifies the query and applies the relevant personal or enterprise metadata filter.
  5. 5. Augmented generation: retrieved context is added to the prompt and Llama-3 generates the final grounded answer.

Core Technical Features

  • OCR pipeline: Tesseract and pdf2image extract usable text from non-textual scans, images, and image-based PDFs.
  • Strict data isolation: personal documents such as CVs and diplomas stay separated from enterprise documents such as policies and reports.
  • Reliable source citations: every answer identifies the consulted files so users can verify the generated response.
